鲸鲸仪表板
v1.9.2
给一台闲置平板做的常驻信息面板 · 打开就是全部，不用点任何东西
01时钟与日历
CLOCK & CALENDAR
  • 秒级大时钟 · 12/24 小时制 · 可隐藏秒数
  • 公历 + 星期 + 农历，离线算到 2100 年
  • 月历固定六行不跳动，上下月补齐弱化
  • 格内小字按 节日 > 节气 > 农历 优先级分色
  • 假期标记、调休显示「班」、今日高亮
  • 点任意日期记日程，按日期存在本机
02天气
WEATHER
  • 双数据源：Open-Meteo 免密钥 / 和风天气
  • 搜索城市或自动定位，Key 只存本机
  • 体感 / 最高最低 / 湿度 / 风力 / 空气 / 紫外线 / 日出日落 / 预报，8 项逐项勾选
  • 3 天或 7 天预报 · 1/2/4 小时自动刷新
  • 拿到数据前先用缓存兜底，不会开天窗
03计时器与闹钟
TIMER & ALARM
  • 倒计时 + 正计时，多个可以同时跑
  • 常用时长一点就开始，能加能删
  • 正计时单独显示在主屏右侧，一眼看到读秒
  • 闹钟支持一次 / 每天 / 工作日 / 周末 / 自选星期
  • 存的是绝对时间戳 —— 刷新、崩溃恢复后依然准
  • 关掉页面期间到点的提醒，回来会补上
04提醒方式
ALERT
  • 响铃 / 震动 / 系统通知，三个开关各自独立
  • 内置 5 种铃声现场合成，不占体积
  • 也能导入自己的音频文件，存在本机不上传
  • 音量渐入，不会突然吓人 · 可贪睡
  • 多路提醒排队，不会互相顶掉
  • 夜间时段可设成计时器只震动、闹钟照响
05AI 问候与人设
AI GREETING
  • 接任意 OpenAI 兼容接口（DeepSeek / 智谱 / 本地 Ollama…）
  • 流式逐字输出，问候语按整点或间隔自动换
  • 每次请求都带上时间、农历、天气、电量等实时上下文
  • 问候语提示词与对话提示词分开可编辑
  • 人设库：可存多套语气，一键切换（内置「大肥鱼」）
  • 点问候语直接展开对话抽屉
06背景与外观
LOOK & FEEL
  • 图片背景，容量约 48 MB，导入只缩不放
  • 按白天 / 夜间自动分组，到点自己换，也能轮播
  • 模糊、淡化、压暗三档可调，保证文字永远看得清
  • 毛玻璃效果（弱机可关）· 内置一张夏日壁纸
  • 双主题：浅色极简编辑网格 / 深色精密数据看板
  • 主题可跟随时间或跟随系统自动切
07适配与常驻
ADAPT & KIOSK
  • 任何横屏 / 方屏都铺满，4:3 到 21:9 都不留边
  • 流体设计单位，元素比例在任何分辨率都不变形
  • Android 壳：开机自启 + 崩溃自恢复，四步逐级兜底
  • 防烧屏位移（阶梯 / 漂移 / 抖动），OLED 友好
  • 夜间勿扰：自动切深色并压暗
  • 配置一键导出导入，单文件 HTML 可直接发给别人
08隐私与数据
PRIVACY
  • 全部数据只存在本机，不上传任何第三方
  • API Key、背景图、日程、计时器、闹钟都在本地
  • 背景图存 IndexedDB，老设备自动降级到 localStorage
  • 导出配置时可选择是否包含 Key 与图片
  • 零第三方依赖，零外链字体，断网也能跑
